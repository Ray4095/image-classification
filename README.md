# Image Classification

## Objective
Train an image classification model using Google Teachable Machine and classify images into two classes.

## Classes
- Cat
- Dog

## Steps
1. Created an image classification model using Google Teachable Machine.
2. Trained the model with two classes (Cat and Dog).
3. Exported the model in TensorFlow → Keras format.
4. Wrote a Python script to load the model and predict the image class.
5. Tested the model using a sample image and saved the output screenshot.
